# Portfolio

Portfolio desenvolvido para divulgação dos meus projetos e do meu trabalho como Engenheiro de Software e Desenvolvedor.

* [**Frontend**](https://github.com/Leandro-Cardoso/portfolio/tree/main/frontend)

* [**Backend**](https://github.com/Leandro-Cardoso/portfolio/tree/main/backend)

## Como executar

Na pasta **backend**:

```cmd
cargo run
```

Na pasta **frontend**:

```cmd
npm install
```

```cmd
npm run dev
```
