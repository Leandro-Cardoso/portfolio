# Frontend do Portfolio

Portfolio desenvolvido para divulgação dos meus projetos e do meu trabalho como Engenheiro de Software e Desenvolvedor.

## Como executar

Na pasta do projeto:

```cmd
npm install
```

Depois:

```cmd
npm run dev
```

Para gerar o build:

```cmd
npm run build
```

Para testar o build:

```cmd
npm run preview
```
